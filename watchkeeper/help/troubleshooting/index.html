Troubleshooting

Messages you may see, what they mean and what to do.

Licence messages

Scroll horizontally to see all columns.

You see What it means and what to do
This licence code was not found Check the code for typing mistakes. Copy it from our e-mail
This licence code was issued for another PC The code is locked to another PC. Write to support@reedoapps.com with this PC's Machine Code
This licence code has expired A code not used within 2 days stops working. Ask us to renew it
Already in use on another PC The code is linked to another PC. Ask us to release it, then enter the code again
This PC is no longer linked to the licence The PC was released. Enter the code again
My level change is not showing Open Settings > About and press Check now

ReEdO AI messages

Scroll horizontally to see all columns.

You see What it means and what to do
No internet connection. ReEdO AI is unavailable Transcription and recording continue. AI resumes when the connection is back. The licence works offline for 14 days
AI temporarily unavailable, transcription continues No AI service answered just now. Try again in a few minutes. If it continues, write to us
This month's ReEdO AI allowance is used Your hours for this month are used. Ask us to add hours, or upgrade
Today's ReEdO AI safety limit The daily limit was reached. Try again tomorrow
This feature needs the Pro or Premium level Press the badge to see what the level includes, or try it for up to 3 days
Talk is an add-on that is not part of your licence Press Request Talk in Settings > Talk

Other problems

Scroll horizontally to see all columns.

Problem What to do
The speech model is not installed Settings > Speech > Download (once)
No transcript from the other people Check your situation in the top bar and the output device in Settings > Audio
My own voice is repeated as THEM, or the other way round Choose the right situation. With laptop speakers, keep Echo cancellation on
Live answers are slow Check your internet connection. A long meeting or a slow connection can delay answers
The update is not offered See Updates
Watchkeeper disappeared when I closed it It is in the tray. Open it from the tray icon, or press Ctrl+Alt+H
Talk will not type in a program Some programs are left alone on purpose. Check Settings > Talk > Keys type normally in

Still stuck?

Write to support@reedoapps.com. Tell us your Watchkeeper version (Settings > About), what you did, and the exact message you saw.
